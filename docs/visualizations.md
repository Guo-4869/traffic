| 图表 | 数据口径 / 交互 |
| --- | --- |
| 今日总览 | 各 App 实际前台区间的并集为总使用时长，分屏不双计；解锁计数使用系统锁屏消失事件，按事件时间去重。环形图为 Top5 + 其他 App，比例以各 App 累计时长总和为分母。 |
| App 排行 | 按所选自然日 / 自然周聚合时长与打开次数；无月排行。仅使用仍在 7 天窗口内的源记录，当前周或缺失区间标注不完整。 |
| 时间轴甘特图 | 一行一个 App，横轴为所选本地自然日；每段使用相同 App 颜色，5 秒合并内的非前台间隔仍留空。点击色块显示起止时间。 |
| 流转桑基图 | 左侧为切出 App，右侧为切入 App；闭合色带宽度与切换次数成正比，双向分别累计。同一 App 可在两侧出现。默认各侧前 8 个 App + 其他，可展开全部 App 节点；聚合前后切换总数守恒。 |
| App × 小时热力图 | 使用实际前台子区间按本地小时切分，深浅对应时长；可横向滑动和点击查询。夏令时回拨的重复小时汇入同一小时列，仍保持时长总和。 |

桌面通过 `ACTION_MAIN + CATEGORY_HOME` 识别，默认桌面和可见的其他已安装桌面均排除。已有桌面会话、名称、流向和前台状态在下一次刷新清理。系统不能解析出的第三方桌面需真机检查，不使用包名关键词猜测。

新事件中忽略桌面，A 离开后 30 秒内进入 B 可计为 A→B；跨熄屏、锁屏、重启不连接。历史桌面流向直接删除，不依据不完整旧信息伪造跨桌面连接。

解锁时间与会话同样只保留 7 天。0.1.0→0.2.0 升级保留已有会话，但过去未采集的解锁不补造；页面显示计数起点。不采集页面、按键、输入内容或解锁认证信息。

验证：24 项基础核心断言、3 项新区间聚合测试、12 项 Android 模拟测试通过；原生截图检查包含有数据、无数据和日 / 周视图。桌面清理、数据库迁移、解锁过期和桑基流量守恒均有回归测试。尚未替代真实手机验收。
