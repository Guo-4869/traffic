# 真机验收清单

开发 APK 的编译、签名检查和 JVM 单元测试不等于真机验证。发布前至少在 Android 9、Android 10+ 多窗口设备和 Android 15 / 目标国产 ROM 执行以下步骤，并记录系统版本、App 版本和通过情况。不要在日志中保存用户实际使用记录。

1. **首次授权**：打开无历史数据；不同意不记录。开启使用权限返回后，只出现同意后的数据。撤权再返回无崩溃，不把空结果报为零使用。
2. **切换**：使用 A 10 秒 → 桌面 → B 10 秒 → A；桌面不出现在时间线和图表中。桌面停留不足 30 秒时非桌面相邻进入计为 A→B，B→A 独立计数；这是统计口径，不证明用户实际点击路径。
3. **5 秒**：A→B→A 且 A 的离开间隔 ≤5 秒，A 打开次数保持一次，但两个方向的流向都保留，A 的前台时长不包括 B 使用时间。
4. **Activity 切换**：同 App 内多 Activity 跳转、旋转屏幕，检查 5 秒合并效果。复杂多 Activity / 分屏场景由于不读取类名、公开 API 无实例编号，可能提前结束包级会话；记录具体机型上的误差。
5. **熄屏 / 锁屏 / AOD**：A 前台后熄屏 2 分钟，再解锁打开 B。A 时长不包含熄屏时间；不产生跨熄屏的 A→B 流向；AOD 不触发采集。
6. **重启 / 关机**：重启后首次解锁前不读取使用事件；未匹配结束显示未知，不把关机事件的持久化时间当作精确关闭时间。
7. **后台 / 强停**：离开 Traffic，检查每日任务可能延迟，允许补算。强行停止后不期望解锁广播拉起进程；再次手动打开补采并显示缺失可能性。
8. **自然日 / 周**：跨午夜、周一、时区变化与 DST；跨日会话时长分别分配，打开次数只在真实开始日计入。
9. **7 天**：测试数据超过 7 天，查询与报表无过期贡献；跨保留边界会话标记截断；旧周报变不完整。重复运行数据库体积不随历史线性增长。
10. **暂停 / 清空**：暂停期间切换其他 App，恢复后不补录；清空后数据和报表均为空，后台任务取消，重新开启不导入之前的历史。
11. **界面**：刘海 / 手势导航 / 横屏 / 大字体，按钮可操作；TalkBack 可读时长与流向图说明。
12. **五图**：Top5 之外归入其他，环形图占比总和约 100%；排行日 / 周切换；甘特图短暂离开处留空；桑基图分支带宽与次数对应；热力图小时合计与已知 App 时长一致。
13. **解锁与升级**：记录开始后锁屏 / 解锁多次再刷新计数；升级不丢会话，旧桌面数据清理，升级前解锁次数不补造。清空同时删除解锁数据，过期解锁不出现在统计中。

电脑上的数据库和首次启动模拟测试（无需连接手机）：

```powershell
.\gradlew.bat :app:testDebugUnitTest
```
