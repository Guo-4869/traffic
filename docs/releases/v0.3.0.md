## 中文

- 新增中文、英文与跟随系统的语言设置，入口：**记录设置 → 语言 / Language**。
- 界面、五种图表、时间格式、授权与隐私提示、无障碍描述均支持双语。
- Android 13+ 与系统的应用语言设置同步；旧版本在 App 内切换，选择重启后保留。
- 继续排除桌面；使用记录仅保存 7 天。切换语言不清空使用记录。

安装 `Traffic-0.3.0-debug.apk`，Android 9+。与之前测试版使用同一签名，可覆盖安装。此为开发测试预发布包，仍可调试，尚未完成各厂商真机验收。

第三方 App 名称按其提供的名称显示，不进行机器翻译。许可为非商业使用；商用及商业合作须通过仓库 Issues 联系作者并取得书面授权。

## English

- Choose **System, Simplified Chinese, or English** in **Settings → Language / 语言**.
- Localized screens, all five charts, dates, consent/privacy messages and accessibility descriptions.
- Android 13+ synchronizes with system per-app language settings. Older versions use the in-app picker. The choice persists after restart and does not clear usage records.
- Home apps remain excluded and usage data is retained for 7 days.

Install `Traffic-0.3.0-debug.apk` on Android 9+. It uses the same signing identity as previous test builds and supports in-place upgrades. This is a debuggable development prerelease; manufacturer-specific device testing remains pending.
